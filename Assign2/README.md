# GNR638 Deep Learning – Assignment 2

## Overview

This repository contains implementations of different deep learning models used for the assignment. Each model is implemented and executed in separate Jupyter Notebook files, but each notebook contain code of all other models (mostly try RESTNET50)

## Files Included

* `gnr638-Densenet.ipynb` – Implementation and results of the DenseNet model
* `gnr638-EfficientNet.ipynb` – Implementation and results of the EfficientNet model
* `gnr638-Resnet50.ipynb` – Implementation and results of the ResNet50 model

## Output and Results

All **model outputs, training logs, and results are already present inside the respective `.ipynb` notebook files**. You can open the notebooks to directly view the results and outputs.

## How to Run the Code

If you want to execute the code again:

1. Open **Kaggle Notebook environment** and use gpu, and connect to internet.
2. Upload or import this repository and also upload dataset.
3. Open any of the notebook files:

   * `gnr638-Densenet.ipynb`
   * `gnr638-EfficientNet.ipynb`
   * `gnr638-Resnet50.ipynb`
4. Run the notebook **cell by cell**.

Each notebook contains **all required steps, including data loading, model building, training, and evaluation**.

## Note

Each model is implemented in a **separate notebook**, and every notebook contains **all necessary cells required to reproduce the results**.
